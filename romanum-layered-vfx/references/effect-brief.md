# Effect brief template

Use this for one effect. Keep it short enough to guide implementation and review.

- Caster, target/impact anchor, direction:

- Visual radius vs gameplay radius:

- Existing VFX, pooling, camera/light ownership interfaces:
- Scope and permitted output:

## Reference evidence

- Creator / original URL / review date:
- Representative sampled timestamps and visible shapes:
- Observed sequence:
- Inferred visual mechanism:
- Proposed implementation:
- Unknown process/toolchain/audio facts:
- Two or three source-specific features the result must retain:

## Phase and layer plan

Record each phase's start/end, silhouette, value, main movement, and transition. For every layer record its job, chosen Roblox primitive, asset origin/rights, tuning parameters, quality tier behavior, and finish/cancel cleanup.

## Asset manifest

For each mesh/texture/flipbook, record name, approved asset ID or local source, owner/license, destination permission, reuse plan, and fallback. Unavailable IDs remain explicit gaps; never invent them. Reference videos are inspiration/evidence, not automatically licensed source assets.

For image-led effects, also record alpha/hole layout, aspect ratio and pivot, atlas crop/padding if used, camera-facing vs world-plane orientation, palette role, layer count separate from unique texture count, per-layer scale/rotation/fade timing, and close-camera transparent screen coverage.

## Review and tests

- Render/camera match and phase snapshots:
- Shape-only and particle/bloom-off reading:
- Gameplay readability near/oblique/bright scenes:
- Low/high quality and actual target device:
- One/concurrent/worst-case cast performance:
- Natural finish, every-phase cancellation, recast, missing asset, nil raycast, caster removal:
- Pass / needs adjustment / not tested for each gate:
- Known unfinished work and next decision:

## Completion

Attach the actual rendered clip/comparison and configuration when available. State tested outcomes; separate planned behavior. Preserve original source attribution. Installation or publication remains governed by the active user request and current permissions.
