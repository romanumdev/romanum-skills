# Numerical hooks and scene examples

Open only the images relevant to the brief. These supplied examples illustrate text treatment, composition and emotional contrast; they are not measured CTR winners, canonical character sheets or evidence of a real game's mechanics. Pass a selected image to the generator only when its style or composition is useful, and identify that role explicitly.

| Example | Readable pattern | Transfer to another game |
| --- | --- | --- |
| [Rainbow production sign](../assets/examples/rainbow-production-sign.png) | One `67QT/s` badge, a large product, a working character and supporting `+1M` pop-ups | Tie the rate to its producer; preserve clear separation between the face, object and label |
| [Production and reward pop-ups](../assets/examples/production-reward-popups.png) | The same income idea with a front-facing character and an isolated reward | Study spacing and text hierarchy without treating a similar layout as a new concept |
| [Day 1 versus day 999](../assets/examples/day-1-day-999.png) | Paired headings, smaller/larger rewards and changing character emotions | Make progression visible in the scene as well as the numbers; source proportions are not the required export format |
| [Production spectacle](../assets/examples/production-spectacle.png) | A rainbow rate headline, a much larger figure and supporting reward effects | Use scale for spectacle only when the figure and interaction fit the game; retain a readable emotional subject |
| [Rare reward reveal](../assets/examples/rare-reward-reveal.png) | One rarity headline and a large focal reward, viewed from a player's perspective | Borrow the reveal structure; do not import dice, bosses or combat into a game that lacks them |
| [Square reward close-up](../assets/examples/square-reward-closeup.png) | A large face and reward with a few `+1M` labels | Compose directly for an icon; reduce supporting text if it competes at small size |
| [Total value and reward](../assets/examples/total-value-reward.png) | One total-value headline with smaller gain labels around the reward | Keep total value, gain per action and production per second semantically distinct |
| [Delivery success and failure](../assets/examples/delivery-success-failure.png) | Foreground grin, background disappointment and an obvious destination, without numerical text | Keep this option when emotion and action already explain the game; numbers are not required |

For a repeated `+1 +1 +1` treatment, adapt the pop-up placement principle to the actual increment rather than copying these examples' `+1M` amounts. The example rarity image reads `1 in 9,342,584`; it does not override a brief requesting `1 in 9,999,999`.

The original files are preserved unchanged. Continue using [the character pack](characters.md) for identity. Do not copy an example's cake setting, currency symbols, scene, aspect ratio or text unless the new brief calls for them. Provenance and file checks are in [the notice](../assets/examples/NOTICE.md) and [manifest](../assets/examples/manifest.json).
