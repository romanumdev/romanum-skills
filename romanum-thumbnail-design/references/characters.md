# Character reference pack

Open these images before generating and pass the relevant files as image inputs. Paths are relative to this file. Keep the full skill folder when installing or sharing it.

| Reference | File | Controls |
| --- | --- | --- |
| Bacon hair | [bacon-hair.png](../assets/characters/bacon-hair.png) | Layered brown hair, blocky silhouette, black jacket, blue shirt, dark trousers, white shoes |
| Acorn girl | [acorn-girl.png](../assets/characters/acorn-girl.png) | Reddish-brown bun/fringe, blue jacket, light striped shirt, muted reddish trousers |
| Wicked smile | [wicked-smile.png](../assets/characters/wicked-smile.png) | Broad toothy grin, brow shape and mischievous gaze; expression only |

These are original reference files, not generated replacements. Preserve identity but adapt pose and expression. Do not reproduce empty borders, background colour, framing or resolution from a reference unless requested. Use the wicked smile only when the scene calls for it; neither avatar has a fixed emotional role.

Use references for characters present in the scene. A solo bacon thumbnail needs the bacon reference and optionally the grin, not the entire pack. When a tool accepts multiple images, identify each role explicitly. If the runtime only loaded `SKILL.md`, retrieve the linked files before promising visual consistency.

File hashes and dimensions: [manifest.json](../assets/characters/manifest.json). Provenance and third-party status: [NOTICE.md](../assets/characters/NOTICE.md).
