# Example provenance

`example-halloween-shop.jpg` is a Roblox Studio Play capture of the Halloween Shop from the studio's own game *Steal Eggs from Area 51*, downscaled to 1000 px wide. The panel, cards and text are native Roblox UI; the egg, props and icons were generated for that game and extracted from its approved concept as described in [prop extraction](../references/prop-extraction.md).

It shows the layout and prop placement only; the motion is described in [the motion recipes](../references/motion-recipes.md). The image is included as a reference for this guide, not as a reusable production asset.
